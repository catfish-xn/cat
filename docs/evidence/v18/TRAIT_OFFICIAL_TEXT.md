# PR #355 羁绊说明：14.24 官方原文

2026-10-21 用户新决定：「羁绊描述直接用原版的就行了或者英文原版的翻译就行了」。此决定覆盖羁绊说明此前“按规则自写简短中文”的约定，以及法师、哨兵展示「全队收益／职业成员额外收益／最终合计」的要求。规则及数值均未改动。

覆盖当前启用的 **25 个羁绊、83 个档位**。24 个使用归档 zh_cn 原文；**百变铁手（High Roller）** 的 zh_cn 缺失，完整翻译同一归档 en_us `TFT13_HighRoller.desc`，保留四种改装及所有数字占位符。未启用的双形战士、强化关系羁绊及三位六费英雄的独立身份机制不属于当前 `TRAIT_DEFINITIONS` 目录，未扩展规则目录。

## 来源与显示

- 来源沿用 `docs/M9_DATA_LEDGER.md` 所指目录：`raw/en_us.json.gz`、`raw/zh_cn.tft.stringtable.json.gz`；全程离线，原始归档未修改。
- `scripts/generate-trait-official-text.cjs` 生成 `src/presentation/trait-official-text.ts`；`--check` 可离线复核。中文原始文本（含标记）原样保存在生成文件中。
- 保留原版 `(人数)` 档位格式、段落、完整句子与各档差异；仅将客户端图标换成对应中文属性名、去除富文本标记，并填入规则实际数值。`expandRow` 按规则表每档展开。
- `traitSummary` 保留外交官等辅助说明。依赖具体对局的 `TFTUnitProperty` 计数行不作为静态规则说明展示，不假填零；黑色玫瑰的静态星级说明保留。
- 家人搞钱、极客幸运／光明装备、执法官没收装备、蓝发十人周期烟雾、黑色玫瑰增伤／复活、野火冲刺／无限攻击距离／爆发攻速、迅击移速／冲刺、统领实际耗蓝、外交官盖伦共享生命均在原句对应位置追加「（暂未实装）」。没有删除原文的延期效果。
- 官方羁绊原文没有单列试验品纹章的分身实验加成，未补写一套新的羁绊规则文案；该既有延期仍见 `docs/V18_TRAIT_EXPANSION.md`。
