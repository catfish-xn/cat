## 通用规则与取舍

规则不读取英雄名、效果名、发射器名或纹理路径。

- 非零出生速度：继续沿速度定向，保持移动射线和光束原有行为。
- 静止且明确为地面层或地形跟随：使用 XZ 平面，保留采样后的平面内朝向。地形跟随仅是平地预览，不模拟导航或真实地形。
- 静止且有出生旋转：按 YXZ 约定、X 反射转换成运行时 XYZ，保留完整平面与平面内旋转。使用平面两条边经过父变换后的叉积检查最终法线；若在数值容差内没有竖直分量，继续跳过。浏览器反例表明，仅有偏航、抵消后的旋转，以及被父变换转成竖直的出生平面，仍会生成竖直长片。
- 没有出生旋转时：明确平面盒或明确扁平圆柱可提供法线；带未解释形状旋转的形状不用于推断。形状、地面和独立父朝向分支同样检查最终组合平面，不能靠出生平面水平就绕过父变换检查。
- 明确局部朝向：使用挂点局部框架，由现有宿主变换跟随挂点，不从绑定权重猜方向。
- 父系统确有朝向变换时：复用现有仿射应用；不重复叠加出生旋转。不把位置或正轴缩放当作朝向证据。
- 其余静止射线返回跳过原因并计数，不再默认为直立局部方向。

恢复项中，地面规则占 20/79，出生旋转规则占 59/79；形状、独立局部朝向及独立父朝向规则均为 0/79，使用合成测试验证，未宣称本地样本验证了这些分支。

复用现有射线的底部锚点几何和完整旋转，无需改变粒子运行时或增加粒子种类。固定射线的带符号尺寸按幅值取均值，避免正负镜像采样相消成为无表面；镜像 UV 翻转明确省略。静态 UV 旋转与原有静态 UV 预览约定一致，保留近似记录。仍不模拟侵蚀、次纹理、随机朝向分布或动态绑定权重。

## 检查与复现

本地 `fixed-plane-rays-baseline.json` 保存旧保护范围，`fixed-plane-rays-audit.json` 保存字段存在性、恢复原因、文档序号和可见采样格数，不覆盖基线。`size-report.json` 沿用实际运行时采样；审计另覆盖所有恢复项，包括未绑定的子系统。

初次重生前才执行基线捕获：

```powershell
node scripts/assets3d/fixed-plane-rays-audit.mjs --out assets3d-local/fx-batch1 --capture
```

六批分别使用对应 `fx-bindings/batchN.mjs` 的单位集合调用 `fxBatch({ units, out, force: true })`；重生后运行审计与 `batchSizes({ out })`。复看命令对每一批执行：

```powershell
$env:CHROMIUM_PATH='C:/Program Files/Google/Chrome/Application/chrome.exe'
node scripts/assets3d/fixed-plane-rays-audit.mjs --out assets3d-local/fx-batch1
node scripts/assets3d/fx-browser-review.mjs --out assets3d-local/fx-batch1 --fixed-rays
```

浏览器仅请求本机；逐项使用非零面积、透明度加权的可见采样，另有整系统斜视和俯视。联系表覆盖恢复项，排除已经保留跳过的竖直长片。格数是几何边长，不是纹理有效像素面积；最大恢复边长约 15.87 格，需要结合窄条纹理判断，不能据此宣称铺屏。

最终浏览器报告与审计逐项核对覆盖 79/79，纹理加载失败为 0/79；地面规则的水平性检查通过 20/20。人工检查六批联系表，并以较小格数视野复看蒙多气泡、克格莫 W；在这些采样中未见恢复项新增竖直长片、白块、黑底或铺屏。洛里斯的父变换反例已移回跳过并刷新第五批证据。此结论限于离线采样，不宣称原版等价或完整对局验收。
