## 通用规则与取舍

规则不读取英雄名、效果名、发射器名或纹理路径。

- 非零出生速度：继续沿速度定向，保持移动射线和光束原有行为。
- 静止且明确为地面层或地形跟随：使用 XZ 平面，保留采样后的平面内朝向。地形跟随仅是平地预览，不模拟导航或真实地形。
- 静止且采样后的出生旋转带俯仰或偏航：按 YXZ 约定、X 反射转换成运行时 XYZ，保留完整平面与平面内旋转。使用平面两条边经过父变换后的叉积检查最终法线；若在数值容差内没有竖直分量，继续跳过。仅有偏航、抵消后的旋转，以及被父变换转成竖直的出生平面，仍可能生成竖直长片。
- 没有俯仰或偏航出生旋转时：明确平面盒或明确扁平圆柱可提供法线；带未解释形状旋转的形状不用于推断。凡恢复规则设置了旋转依据（地面层、出生旋转、形状法线或父朝向），均检查与父变换组合后的平面法线；组合后竖直则跳过。宿主挂点局部朝向继续由播放时宿主提供；完全没有朝向依据的旧画法仍豁免。
- 明确局部朝向：使用挂点局部框架，由现有宿主变换跟随挂点，不从绑定权重猜方向。
- 父系统确有朝向变换时：复用现有仿射应用；不重复叠加出生旋转。不把位置或正轴缩放当作朝向证据。
- 其余无朝向依据的静止射线保留本 PR 前的局部方向画法；零出生旋转、仅平面内旋转本身不触发新的竖直跳过；若另有恢复规则生效，仍检查组合后的平面。不加单英雄例外。

恢复项中，地面规则占 20/79，出生旋转规则占 59/79；形状、独立局部朝向及独立父朝向规则均为 0/79，使用合成测试验证，未宣称本地样本验证了这些分支。

复用现有射线的底部锚点几何和完整旋转，无需改变粒子运行时或增加粒子种类。有平面依据的固定射线，其带符号尺寸按幅值取均值，避免正负镜像采样相消成为无表面；镜像 UV 翻转明确省略。无朝向依据而走旧画法的射线仍按带符号均值采样，不把旧有零表面变成新可见片。静态 UV 旋转与原有静态 UV 预览约定一致，保留近似记录。仍不模拟侵蚀、次纹理、随机朝向分布或动态绑定权重。
