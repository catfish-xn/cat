## 通用规则与取舍

规则不读取英雄名、效果名、发射器名或纹理路径。

- 非零出生速度：继续沿速度定向，保持移动射线和光束原有行为。
- 静止且明确为地面层或地形跟随：使用 XZ 平面，保留采样后的平面内朝向。地形跟随仅是平地预览，不模拟导航或真实地形。
- 静止且有出生旋转：按 YXZ 约定、X 反射转换成运行时 XYZ，保留完整平面与平面内旋转。使用平面两条边经过父变换后的叉积检查最终法线；若在数值容差内没有竖直分量，继续跳过。浏览器反例表明，仅有偏航、抵消后的旋转，以及被父变换转成竖直的出生平面，仍会生成竖直长片。
- 没有出生旋转时：明确平面盒或明确扁平圆柱可提供法线；带未解释形状旋转的形状不用于推断。形状、地面和独立父朝向分支同样检查最终组合平面，不能靠出生平面水平就绕过父变换检查。
- 明确局部朝向：使用挂点局部框架，由现有宿主变换跟随挂点，不从绑定权重猜方向。
- 父系统确有朝向变换时：复用现有仿射应用；不重复叠加出生旋转。不把位置或正轴缩放当作朝向证据。
- 其余静止射线返回跳过原因并计数，不再默认为直立局部方向。

恢复项中，地面规则占 20/79，出生旋转规则占 59/79；形状、独立局部朝向及独立父朝向规则均为 0/79，使用合成测试验证，未宣称本地样本验证了这些分支。

复用现有射线的底部锚点几何和完整旋转，无需改变粒子运行时或增加粒子种类。固定射线的带符号尺寸按幅值取均值，避免正负镜像采样相消成为无表面；镜像 UV 翻转明确省略。静态 UV 旋转与原有静态 UV 预览约定一致，保留近似记录。仍不模拟侵蚀、次纹理、随机朝向分布或动态绑定权重。
