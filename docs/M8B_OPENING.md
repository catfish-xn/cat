## 1. 对齐的旧起手及比较时点

已核对基线为 `feat/m8-b0-baseline@877c59b2babc4c6abfccc62452075f3b0cbbd688`。旧版本直接从 2-1 开始：10G、等级 3、0XP、100HP，刀妹/麦迪/拉克丝各一星，先完成两次组件选择，再进入 2-1 强化选择。

新方案的比较时点为：**进入 2-1，按正常锁店规则完成该轮商店处理，尚未选择 2-1 强化**。基准路线无购买、出售、D 刷新或 F 买 XP，不计算强化带来的额外金币；执行必要的开战、继续、两次组件选择，允许人工上阵和移动；三场 PvE 全清，奖励英雄均可入备战席。

此基准应精确达到 **10G、等级 3、0XP、100HP、指定三英雄各一星、2 个自选永久组件**。这是资源对齐，既不要求同 seed 的商店报价和战斗轨迹仍与旧版本相同，也不新增自动上阵。新获得的麦迪/拉克丝进入备战席，玩家决定部署位置；遭遇强度是否允许完全不部署地全清，属于后续战斗验收，本文不宣称已经验证。

## 2. 1-1 初始化与单位身份

1-1 只是创建新局的初始化语义：设为 0G、等级 1、0XP、100HP，发放一星刀妹 `definitionId=irelia`，实例为 `unit-1`，沿用旧起手坐标 `(col=1,row=4)`；下一永久英雄序号为2。刀妹不是一次野怪掉落；初始化不消费英雄随机词。

初始化直接进入 **1-2 准备期**。不新增可操作或可保存的 1-1 中间 phase，不新增第四场 PvE，不新增一条推进轮或战斗档案；按三个阶段 1 PvE 计算，完整日程仍为条件已明确后的 38 个推进轮、33 场战斗。

1-2 的指定怪物奖励固定麦迪 `maddie`，1-3 的指定怪物奖励固定拉克丝 `lux`，均为一星，英雄种类不随机。实例 ID 通过既有单位序号分配；无购买基准下可依次得到 `unit-2`、`unit-3`，但不能为此覆盖玩家操作已经使用的序号。新英雄进入备战席，不回写本场 Combat 快照，也不自动上阵。

### 3.1 基础收入与失败规则

| 项目 | 阶段 1 首版规则 | 2-1 起 |
| --- | --- | --- |
| 基础金币 | 1-2/1-3/1-4 分别 2/3/5G，每轮只结算一次，胜败均发 | 沿用原每轮 5G，包含 PvP/PvE/补给 |
| 自然 XP | 分别 2/2/0；1-4 明确不发 XP | 沿用原每轮 2XP及等级上限处理 |
| 利息 | 0；不按阶段 1 手持金币结息 | 沿用原利息规则 |
| 胜利金币 | 0 | 仅 PvP 胜利沿用原 1G |
| 连胜/连败 | 阶段 1 不更新计数、不发该项金币 | 沿用原 PvP 更新与发放，PvE/补给不推进计数 |
| PvE 失败或平局扣血 | **沿用当前固定 3HP**，不加存活怪数量 | 原 PvE 同样保留固定 3HP |
| PvE 胜利扣血 | 0 | 沿用当前规则 |

2/3/5G 是基础收入，不是未击杀掉落，也不是恢复旧版失败补给。未击杀的麦迪、拉克丝或组件按掉落政策作废；不能因为目标是对齐旧起手，就在 2-1 额外补足。玩家因失败失去 HP 时，也不能重置回 100HP。

阶段 1 失败后仍存活则正常结算和推进；玩家 HP 归零则按合同增补完成本轮实际授予后终局，不要求完成三场，不额外发未到轮次的收入或 XP。

### 3.2 XP 手算

沿用 `XP_TO_NEXT_LEVEL` 中 1→2 需要 2XP、2→3 需要 2XP：

- 1-2：等级 1、0XP，加 2XP → 等级 2、0XP。
- 1-3：等级 2、0XP，加 2XP → 等级 3、0XP。
- 1-4：加 0XP → 等级 3、0XP。

合计自然 XP 为 4。不能把旧统一每轮 2XP直接套到三场，否则 2-1 会变成等级 3、2XP。玩家主动 F 买 XP 时按既有 XP 函数累计，基准值不覆盖其合法成长。

## 4. 商店、操作与原语义节点

商店从 1-2 准备期开放，采用当时等级的现有五格商店、费用概率、无限池与锁店规则。1-1 没有独立商店或操作窗口。无锁店基准下，1-2/1-3/1-4/2-1 依次按等级 1/2/3/3 生成商店；锁店时按既有免费刷新规则处理，不为了账本强制解锁。

购买、出售、部署、D 刷新和 F 买 XP 继续受准备期、金币和部署上限约束。阶段 1 允许玩家主动运营，因此有操作路线不应被强制拉回 10G 或三级。1-2 的基准金币为 0，不承诺玩家无需出售就能购买英雄。

**商店 RNG 不重置。** 增加阶段 1 的正常商店处理后，后续同 seed 报价可能改变；这是新版本轨迹，不应复用旧报价 golden 宣称完全相同。

**battle-seed 流也不重置。** 三次成功开战分别按现有 `startMatchCombat` 消耗一个 battle-seed 词，总计前插三个词，因此原 2-1 及后续同 seed 战斗不承诺重现旧轨迹。失败的开战命令仍不消耗词。上述变化不允许窃贼、选择或掉落去借用商店/战斗随机流。

强化仍位于 **2-1、3-2、4-2**，异常仍位于 **4-6**；五次 `.4` 补给和 6-7 终点保留。事件按稳定 roundId 挂载，不把旧数字序号机械加三后视为全部兼容。第一阶段已经替代旧10G/三级/三英雄/两次组件，进入2-1不得重复执行旧起手事件。
