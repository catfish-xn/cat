# M4 Combat contract v4

Match compiles `buildStrategySnapshot`, then calls `createCombatWithEvents(preparation, strategy, combatId)`. Snapshot excludes bench and freezes distinct-board trait tiers, item/augment/Anomaly sources, resolved stats/ability and zeroed per-effect counters. Neither later Match changes nor catalog reads affect a running battle. Low-level `createCombat(GameState)` remains available for unchanged M3 mechanics tests with no modifiers. Types live in combat-types.ts and strategy-types.ts; exact rules live in [M4_RULES R7–R9](../M4_RULES.md).

- 50ms/tick, max1200ticks, movement every5ticks. Fixed neighbor order E,SE,SW,W,NW,NE; targets nearest then code-point ID. Move intents share occupancy snapshot, ID reservations prevent swaps/overlap. Output units/events are deterministic under input permutations.
- New snapshot fields: starLevel, armor, magicResist, mana/maxMana, shield/expiry, resolved Ability data. HP full, Mana initial, shield0/expiry null, cooldown0/target null each battle.
- Tick stages: decrement cooldown and expire shields; plan/reserve movement; plan all attacks/casts from post-movement alive snapshot; collect corresponding hooks; commit all shields; per-packet mitigate then aggregate damage; apply HP simultaneously; collect surviving onHpLoss hooks; award surviving Mana; clear dead fields; elimination before timeout.
- Full Mana plus valid target casts with priority, regardless of attack cooldown; spends Mana, excludes same-tick autoattack, resets attack cooldown. Damage abilities use attackRange and current nearest enemy, radius0/1. SelfShield needs an enemy but has no range restriction. Invalid cast doesn't spend Mana.
- Attack gains10Mana. Surviving recipient gets min(20,floor(actual aggregate HP loss/10)); shields/overkill grant no damage Mana. Clamp max; newly gained Mana only casts next tick. Committed effects still land if caster dies this tick.
- Raw0→0; positive damage max(1,floor(raw*100/(100+resistance))). Physical armor/magic MR; resistance finite nonnegative. Round each packet then aggregate. Damage event amount=mitigated incoming, physical/magic sums, absorbed, actual hpDamage, final hp/shield.
- SelfShield uses max(existing,grant), expiry=tick+duration. Expire at tick>=expiry; zero shield always null expiry. New shield protects this tick. shieldChanged signals grant/refresh/real expiry; damage reports absorption without another duplicate shield event.
- Event order: expired shields(ID), movement(ID), all primary attack/cast(source ID), their effectTriggered events, granted shields(ID), damage(target ID), onHpLoss effectTriggered, manaChanged(ID), death(ID), at most one combatFinished. manaChanged also includes hookGain. Every M4 Combat event carries domain/combatId/tick/eventSeq; identical payloads from different sources remain separate events.
- Primitive arithmetic is star stats → summed flat → summed percentage → one floor → clamp. Attack speed uses one ceil and a minimum one-tick interval; initial Mana clamps to maxMana. Source order is owner ID, trait/item/augment/anomaly/enemyGrowth rank, definition ID, instance ID, effect index. All comparisons use code-point ordering.
- Hooks are combatStart, onAttack, onCast and onHpLoss, with independent everyN counters. Actions are self shield, self Mana or one physical/magic packet against the primary enemy. onHpLoss only grants Mana. Derived packets never recurse or increment attack/cast counters. Simultaneously planned actions survive the source's death; HP-loss Mana requires survival and actual HP loss.
- combatStart applies once at tick zero, before the first regular tick, and returns its events to MatchSession. Empty-team tick-zero results skip hooks. Across a shield batch, amount is max(existing, grants) and expiry is max(existing, grant expiries), with null expiry at zero shield. Every new battle resets counters and transient HP/Mana/shield; traits remain frozen even after a member dies.
- Dead units remain hp0/alive false/target null/cooldowns0/Mana0/shield0. Finished step returns the same state and empty events. Empty or single-sided low-level combat ends tick0; it need not emit a step event. Match separately permits an empty-player concession, rejects absent enemies and owns HP/XP/economy settlement.
- Renderer reads committed state/events only. Tween completion, frame timing and keyboard repeats do not calculate gameplay. Frame accumulator preserves partial ticks; deterministic replay uses logical ticks, not arbitrary decimal wall-time sums.
