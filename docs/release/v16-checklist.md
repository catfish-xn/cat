## 五、旧存档与发版操作（公告要写）

- **发版前排空对局**：先看 `/healthz`，`room` 为 null 或 `phase` 为 ended 再停服务；有真人在打就等。
- **联机**：服务器不存档，重启后旧对局和座位凭证全部失效。netProtocol 3 → 5，旧页面连新服务器会提示“版本不一致，请刷新”。玩家刷新后重新匹配。
- **单机存档不能续玩**：规则 v14 → v16、内容 digest ea6b11b6 → de829c8a、命令协议 3 → 4，旧存档按严格边界拒绝，不迁移（用户 10-20 已批改存档格式）。提醒玩家在 `/cat/` 更新前到“开始与继续”里“导出当前局”留底。
