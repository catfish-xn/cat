# 第三批粒子浏览器复看

资源及原始侧写仅保留在 `assets3d-local/fx-batch3/`；本文仅记录比例、格数和结论，不收录源数值、贴图名或逐发射器原始字段。全程离线，不执行 Git 操作，不改规则或界面入口。

## 白块与通用修复

Garen R_AoE_Impact 的白块来自 FireWave。浏览器逐发射器隔离能重现，PNG 加载及透明通道正常。近似转换丢掉旋转发射坐标系，又把随机参数取均值，使连续发射的粒子沿同一路径大量重叠，叠加饱和后形成实心白色轮廓。

通用策略：连续发射同时依赖旋转发射坐标系与非零出生速度时，当前运行时无法表达其分布，跳过并按原因计数。没有英雄、技能或贴图名特判；单发、零速度或零旋转不触发这项保护。

顺查发现 Ambessa R_Hurl_Impact 的浅灰矩形属于另一条路径：不透明底图依赖副遮罩定义轮廓，而近似转换省略副遮罩。通用策略：确认底图无有效透明度，且存在当前无法表达的副遮罩时，跳过并按独立原因计数。具有自身透明轮廓的底图不触发这项保护；未知透明度不冒充已确认不透明。

上述处理是有记录的视觉省略，不代表还原了原版分布或副遮罩。严格转换路径不变。

第三项通用改动是长边包络扩展：此前仅显式面片使用 XY 长边包络，本 PR 将其扩展到射线、缺省图元（按相机面片处理）和网格。射线与缺省面片使用 XY；网格使用实际几何包围尺寸加权的 XYZ。标量曲线保留各时刻最长边，并在轴主导权切换处插键；仍近似固定宽高比，不代表完整还原各轴动画。这会改变第一、二批的既有尺寸，并非只影响第三批。
