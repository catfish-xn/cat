# 棋盘

S13 默认待核实。当前 `board-default` 保留通用竞技场；未发现足以将其他战斗棋盘认定为 S13 专属默认的绑定证据。

已离线检查固定版本客户端的以下类别：

- Map22 地图总配置、地图皮肤列表与默认地图皮肤的场景引用。
- S13 赛季配置及资源解析器的场景绑定；明确的赛季场景引用属于轮盘，不能据此替换战斗棋盘。
- 竞技场皮肤相关索引、通用竞技场场景与几何资源分类；名称或赛季主题不作为默认身份的证据。
- TFTSet13 与公共资源包的实际文件索引；未发现可确认专属默认战斗棋盘的独立场景配置。
