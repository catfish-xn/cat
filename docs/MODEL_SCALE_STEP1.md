# 模型尺寸核查：第 1 步（2026-10-21）

基线为 PR #369（已合入 multiplayer）。本步只增加离线读取工具和合成测试，不修改 `src/`、`merge-root-output.mjs`、FX_SCALE 或模型网格。原始数值、素材和截图均在忽略目录 `assets3d-local/model-scale/`。

## 数据交付

- 63/63 英雄（包括三名六费）和 12/12 PvE 均取得所选皮肤的显式官方值；官方缺省、读取失败及回退名单均为空。
- 素材根：`assets3d-local/model-scale/root/manifest.json`。75 个单位写入可选数值 `models[id].unitScale`，通过本分支真实 `assertManifest`；场景和小小英雄映射不变。
- 来源为 `SkinCharacterDataProperties.skinMeshProperties.skinScale`；读取器也接受对应 TFT 类型。所选皮肤和 root 的同名值不能相乘。角色记录未发现明确模型乘数；血条高度、选取高度/半径不作为乘数。
- 完整本地报告为 `REPORT.md`，逐单位尺寸表为 `size-comparison.csv`，核验摘要为 `verification.json`（均相对于上述本地目录）。文档不复制原始素材名称、路径或官方数值。

## 核查结果

阿木木修正后的绑定高度约为旧版的 **0.570 倍**，吉格斯约为 **0.492 倍**；两者明显低于金克丝。实际调用 #369 的 `fitModel` 测量，按旋转包络直径限制占格。英雄有 23 名、PvE 目标算法有 4 名触发宽度上限，完整名单只在本地报告。

| 五项核查 | 阿木木 | 吉格斯 |
| --- | --- | --- |
| 动作/骨骼 | 所选官方动画图引用全部导出动作；有多余未匹配轨道，但变形骨骼及祖先全部覆盖 | 官方动画图引用全部导出动作，无多余未匹配轨道，变形骨骼及祖先全部覆盖 |
| 非均匀缩放 | idle 首帧三轴均为单位缩放，主体根和髋未异常上移 | 同样没有非均匀缩放或异常上移证据 |
| 隐藏子网格 | 皮肤要求隐藏的现有子网格未绘制，未撑高整体盒 | 单一子网格，无隐藏项 |
| 绑定/idle | idle 高度约为绑定的 0.941 倍，没有从矮绑定姿势突然拉长 | idle 高度约为绑定的 0.996 倍 |
| 皮肤 | 所选 TFT 默认外观的网格、骨骼和官方图一致，动作文件沿用其他皮肤编号命名不构成错配证据 | 所选默认外观一致 |

ANM 不含独立参考绑定骨架，不能宣称两套绑定骨长完全相等；已比较骨骼哈希、局部平移长度和 precise 姿势尺寸。当前没有需要换皮肤或修提取的证据。

`review/` 下有 16 张截图：两英雄各自绑定/idle/攻击的前后对比共 12 张，以及邻格五英雄、每费两名、满备战席和选秀转盘。逐姿势对比固定动画时间和摄像机；四场景使用当前实际渲染器及新素材根，英雄均非占位模型。浏览器仅读取 `CHROMIUM_PATH`，只允许本机请求。

## 留给 3D 线的接线与验收残留

1. PvE 的 `unitScale` 已交付，但现有独立 monster 分支仍使用旧归一化，实际显示不会随新字段改变。本地表明确区分现有尺寸和目标算法测量；需由 3D 线接入，保留旧素材兼容。
2. 绑定姿势均未超一格；动画首帧的可绘制索引网格仍有娜美 idle **1.066 格**、特朗德尔 idle **1.014 格**、盖伦攻击 **1.196 格**。所以“所有动画均不出格”的目视标准尚未满足，完整动作包络也未验收。建议独立修限宽依据，不改单个官方 `unitScale`。

## 工具与验证

`node scripts/assets3d/unit-scale.mjs <local-job.json>` 接受本地作业：`manifestPath`、全新 `outputManifest`、`selections: [{ ids, skinBin, skinEntryHash?, meshPath?, multipliers? }]`。输出只允许在 `assets3d-local/`；不会覆盖已有文件。调用方先核实素材版本和摘要；输入缺失或皮肤歧义直接停止，不能伪装成官方缺省。字段真实缺省才取单位值。额外乘数必须先明确其模型缩放语义，再显式提供字段名和值。

5 项纯合成测试覆盖二进制读取、缺省与读取失败的区别、皮肤歧义、无效值、显式乘数以及 #369 的真实 schema 边界；`tsc --noEmit` 通过。当前环境默认 esbuild 配置加载受限，测试使用 `node node_modules/vitest/vitest.mjs run --configLoader runner --project fast tests/assets3d-unit-scale.test.ts`。实际素材另核实 CLI 输出一致、原 manifest 其他字段保留、载荷摘要一致和真实渲染器缩放一致。
