## 家人5任务及奖励法球

权威任务在 `seatMechanics.hidden.progress.family`：`CurrentReward / CurrentProgress / CurrentRewardValue`、sequence、冻结payloads及独立rngState/rngDraws。随机流初态 `seed XOR 0x66616d35`，`lcg32-v1`。每个任务先消耗1词取16候选；每个随机组件/神器另消耗1词，使用 `floor(word * poolSize / 2^32)`；其他固定载荷不抽。领取、读取、失败、暂停和恢复不推进该流，也不使用商店/战斗/经济RNG。

每场开战家人5已激活的PvP：阶段2加2；阶段3加2+S；阶段4及以后加3+S。S只含开战部署且终战仍存活的真实家人实例，排除分身、召唤、假人和备战席；羁绊激活仍按不同英雄去重。PvE完全不推进。达到目标生成 `family:orb:<sequence>`，只减当前目标，抽并冻结下一任务；本战不继续检查新目标。不存在每局三奖上限。

| 目标 | 候选（每项权重1） |
| --- | --- |
| 10 | 训练假人替代：10金（魔改）；1星成年蔚+1星金克丝；金铲铲；金锅铲 |
| 17 | 窃贼手套；3个普通次级英雄复制器；2个随机组件；鱼骨头 |

随机组件池为既有 `COMPONENT_POOL` 八项（排除铲/锅）；神器池为 `G24_FORGE_POOLS.TFT_ArmoryKeyOrnn` 全29项，无额外排除；池内等权、组件允许重复均为未验证/魔改项目约定。奖励不直接到账，也不自动drain。法球由已冻结G23 bundle减去唯一原子领取收据投影，避免第二份可写库存；金币也要领取。

`claimOrb(state, orbId, expectedRound, policy?)` 沿公共签名领取（家人法球也支持单人）；联机经 `runSharedMatchCommand({type:'claimOrb',...})`。每个可容纳原子独立领取，满备战席英雄留原球，其余继续；重试不重抽。英雄2星直接按3份共享库存预留；池不足沿既有按基础费用补金，满席保留，不把家人奖励另改为自动卖出。战斗时只记FIFO意图，结算后领取；取消/重复/错误轮次不会产生额外资源或RNG。常规失败沿既有 `stale-round / wrong-phase / shared-pool-required / unknown-orb / already-claimed`，原state及资源不变。

`readG23MechanismState(state)` 增加 `familyHeist`（三字段、currentRewardName、progressText、policy）、`familyReunion`及`mel`投影。`seatMechanics.seat.familyHeist` 为相同本人显示字段，不含载荷随机游标；`readLootView().unclaimedOrbs` 增加 `source:'family'`。说明底部的进度/奖励/目标由这些显示字段提供，界面不得自行累计或重抽。展示接线继续由Claude负责；本任务只修改说明文字和数据合同，未改渲染目录或舞蹈动画。

## 彩蛋和六费战斗

`familyReunionParticipants(inputs, team?)` 纯读，六名必须在场：violet/vander/powder，以及各携带家人纹章的 warwick/jinx/vi。无站位/星级/强化/任务门槛；额外家人不扩大名单。每英雄只选择ID最小的真实实例。`familyReunionView(inputs)` 返回资格、六实例ID、原星级/战斗星级、回移和未验证政策字段。准备期的跳舞资格由领域提供，动画交给表现层。

`buildStrategySnapshot` 在应用全部装备/羁绊来源之前以战斗有效星级重新编译base与技能，只对上述六人+1（最高4）。`StrategyUnitSnapshot / CombatUnit.familyReunion` 冻结原星级/战斗星级及`unboostedStarLevel`（不含彩蛋的有效星级，保留终极英雄等独立四星来源）；`effectiveStarLevel` 为战斗显示星级，物理`Unit.starLevel`和卡池份数不变。复制体不继承彩蛋，战后准备状态未被修改，下战重新判断。

首个参与成员的真实阵亡（保命/复活裁决及死亡清理之后）调用 `settleFamilyReunionDeaths(ctx, roster): void`，按队伍撤销其余存活参与者的额外一星；不因非参与者阵亡或暂时离场触发。完整roster含暂时放逐者，队伍互不影响。全部六人记录 `CombatUnit.familyReunion.downgradedAtTick`，后续阵亡/重复调用不再退星，不消耗RNG。按 `unboostedStarLevel` 重算基础生命/攻击及后续技能，装备、羁绊与动态成长来源保留。生命换算为 `max(1, floor(beforeHp * afterMax / beforeMax))`；现有护盾与已排定技能包保留授予/规划时快照，不重发收益。发出既有 `maxHpChanged / statChanged` 事件，显示回放由 `unitUpdated.effectiveStarLevel` 同步。退星规则为**未验证（PBE 观察）**，生命同比例换算和保留快照为项目执行约定，不宣称来自官方脚本；恢复仍从冻结输入逐tick重演并核对完整状态。

六费配置在 `content/v19-six-cost.ts`，稳定单位键严格为 `warwick / viktor / mel`（梅尔源API `TFT13_MissMage`）。维克托初始3/8能量，每攻击+1，满8后下一次行动施法清零；射线的两格映射为主目标格＋沿施法者到目标方向最接近的后一格（cube向量点积、row/col稳定破平）；射线两包均不暴击、射线自身不消费暴击RNG词，为项目分包口径，原版未验证。射线魔伤50/180/2000×AP/100及固定真伤25/90/1000，附30%双破抗5秒；全场击飞2/3/30秒，落地100/300/9999×AP/100＋目标最大生命8/20/100%魔伤。

沃里克技能4秒嗜血，基础每秒180/300/1088＋AD×AS×2/3.75/25物伤；吸血为10%＋10/15/100%×AP/100。当前周期包覆盖邻格一圈敌人、与普通攻击并行，首脉冲在施法后20tick，4秒末脉冲计入；目标映射/普攻并行缺少消费脚本，属未验证/魔改执行约定。吞噬绕过盾，遵守免伤/免死/复活裁决，最终真实死亡才发一次400治疗、50法力并计击杀；五杀后永久嗜血且不再被控制打断。试验品实验格共享沃里克击杀邻格眩晕1秒，7档2秒；实验格、100/300/300生命和既有去重政策沿用。

梅尔每个副本独立记录施法数、储能及护盾来源；自己的盾（包括给盟友的盾）每实际吸收2伤害存1能量，保留半点余数。普通施法至多3敌各180/450/2700×AP/100魔伤；第三次按上表。玩家PvP施法数从冻结战斗事实`g23Facts.melCasts`汇总，PvE/镜像不计；包含本战第12次，在Match扣血/淘汰前拦截首个致死到1HP。唯一`mel-save`经济收据和`playerSaved`事件保留整局资格，出售/重买不重置；当前与后来梅尔均+10%增伤。

`CombatUnit.sixCost` 保存能量、转入法力、嗜血时钟/击杀、吞噬收据/候选、梅尔储能余数及风暴延时任务。领域账本新增 `chaosEnergyChanged / bloodFrenzyChanged / devoured / melEnergyChanged`，盾仍用`shieldLayerChanged`；公开回放按白名单投影这些动画事实，完整状态由权威重演校验。无这些来源的战斗拒绝伪造sixCost/familyReunion字段。

## 商店、存档和验证边界

每个非空商店格仍消费两个LCG词：费用词、英雄词。4-6前保持旧1–5费映射；解锁后费用词同时决定六费及普通费用（六费失败区间重映射到原普通表），英雄词按六费剩余份数加权。六费空池排除该tier，普通库存按正概率归一；锁店不抽、空格零词。自然刷新使用**进入**的回合ordinal；共享八席先全部释放再按既有顺序预留。复制器不创造无限卡；六费池空使用复制器在共享入口原子拒绝。未开放强化赠六费、奇遇、选秀、箱子/法球新增随机六费渠道；这些表仍显式1–5费。

`validateG23Progress` 从经济事实完整重演任务/载荷/RNG/进度/保命资格，再核对所有原子收据；显示字段必须匹配权威任务。涉及家人5经济或梅尔PvP施法的单人历史恢复，要求完整battles作为独立历史证据。新六费/彩蛋动态战斗从认证输入逐tick重演，拒绝伪造状态；恢复不发奖、不重抽。旧存档保留原件导出，不静默迁移。联机完整Match存档仍不支持，发布前需排空旧对局。
